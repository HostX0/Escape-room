# Escape Room backend

Express 5 API with PostgreSQL. See ../README.md, ../docs/DEPLOYMENT.md and ../docs/QA.md.
No default accounts or passwords are included. Use the opt-in seed:test command only on a dedicated test database.
Tests without RUN_DB_TESTS=1 do not exercise a real database. Font files are installed from the upstream source at build time, not distributed in this repository.
